LEGACY RESULTS - SUPERSEDED
===========================

These workbooks and figures came from "experiment V1 (base ensemble model).py",
which predates the canonical split. It calls train_test_split() itself while
loading branch checkpoints trained on a different partition of the same rows, so
its test set overlaps the branches' training data.

The many near-duplicate files here (DRSE_Ensemble_Results.xlsx,
DRSE_Ensemble_Results2..5.xlsx, DRSE_Calibrated_Results*.xlsx) are successive
re-runs during development, not distinct experiments. There is no record of
which run corresponds to which configuration.
